# 00 · 范围与验收

本文件是 XP 精简客户端的**范围基线**。任何超出下表 In 的请求都算范围变更，需要重新估工时。

## 1. In —— 本版本要做

| 模块 | 具体内容 |
| --- | --- |
| 数据层 | 读写主程序的 `ort_plans.db`：连接/事务/忙等待重试、日期与布尔值格式、表存在性探测；覆盖本范围用到的表（users、user_roles、plans、requisitions、plan_change_logs、app_settings、mail_logs、customers、products、model_mappings、code_mappings、stages、test_items_catalog） |
| 登录 | 用户名 + 密码校验（与主程序同一套 SHA256(salt+password) 散列）、角色读取、`IsActive` 判定、无密码账号直接放行、记住登录（本机凭据文件 + DPAPI） |
| 领用与计划表 | 两个页签的列表、搜索、排序、刷新；领退单新增/编辑（含工令号与回线RT 校验、单体去向、下拉取值）；计划表新增/编辑/删除；写 `plan_change_logs` |
| 邮件 | SMTP 发送（None / StartTls / Ssl 三种安全方式）、收件人解析（用户表邮箱、角色邮箱）、计划到期提醒（结束日期 − 提前天数、未结案、逾期）、`mail_logs` 发送记录与去重、精简设置界面、测试发送 |
| 交付 | onedir 打包、部署说明、XP 实机回归、已知限制清单 |

## 2. Out —— 明确不做（不估工时）

- 报告生成全链路：Excel/Word 模板、OpenXML 部件改写、OLE 嵌入、Word→PDF、iText 相关处理
- 报告链接与报告文件夹扫描、计划索引（`report_links`、`plan_index_*` 表）
- 审核流（`review_requests`）、流程状态窗口、回线/入库/报废登记窗口、领退↔计划互转
- 管理端：用户管理、测试项与目录维护、`test_plans` / `plan_item_templates`
- 界面体系：多语言（zh-CN / zh-TW / en）、4 套主题、UI 缩放、Toast、更新日志窗口
- 交互细节：列筛选多级合并、列宽/列序记忆、拖拽排序、暂存批量提交、Excel 导入导出
- 与审核相关的邮件通知（提交/审批/密码变更/邮箱缺失）
