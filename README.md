# ORT实验室管理系统

> 实验室 ORT（Ongoing Reliability Test）业务的桌面管理系统：样品领用与退库、测试计划排程、测试报告一键生成、计划变更审核、到期提醒，全部在一个 Windows 客户端里完成。
>
> 语言：简体中文 / 繁體中文 / English　｜　界面：WPF（.NET Framework 4.8）　｜　数据：SQLite（可放网络共享，多台电脑共用一套数据）

- 仓库名与根命名空间：`ORT一键报告`（历史名，保持不变）
- 生成的程序：`ORT实验室管理系统.exe`
- 当前版本：见 `Properties/AssemblyInfo.cs` 的 `AssemblyVersion`

## 功能概览

| 模块 | 入口 | 说明 |
| --- | --- | --- |
| **一键报告** | 主界面「一键报告」 | 选报告概览 → 自动读取表头信息与本次测试数据 → 按模板生成完整报告（含图片、ATE 数据、结论）。 |
| **领退和计划** | 主界面「领退和计划」 | 核心工作台：领用/退库登记、测试计划排程、回线·入库·报废登记、报告状态跟踪、列筛选与批量操作。 |
| **审核** | 主界面「审核」 | 普通用户的更改请求进审核队列，管理员逐条通过/驳回；支持旧值与新值逐字段比对。 |
| **管理** | 主界面「管理」 | 人员与权限、客户、测试项目、产品别、测试阶段等基础数据维护与导入。 |
| **报告模板工具** | 主界面「设置」旁菜单 | 由机种测试计划直接生成报告模板。 |
| **邮件提醒** | 自动 | 计划临近结束日期、审核通知、密码变更等按规则发邮件；可配置 SMTP、模板与抄送。 |
| **后台自动任务** | 自动 | 空闲时自动建立计划索引、自动扫描报告夹回写报告状态；不会打断前台操作。 |
| **后台运行** | 设置 → 后台运行 | 关闭主窗口可最小化到托盘继续跑；支持开机自启（本机路径）。 |

## 运行环境

- Windows 7 SP1 及以上（建议 Windows 10/11）
- .NET Framework 4.8
- Microsoft Excel（仅「OLE 附件嵌入」与部分报告处理需要；纯 NPOI 路径不需要）

## 快速开始

1. 解压发布包到**本机磁盘**（不建议放在网络共享里运行，见[常见问题](#常见问题)）。
2. 双击 `ORT实验室管理系统.exe`。
3. 首次启动弹出登录窗口：
   - 没有账号时点「游客登录」可以进入界面浏览（业务功能仍受权限限制）；
   - 管理员登录后可到「管理」里建账号。
4. 建议先进「设置」把路径配好（见[设置说明](#设置说明)），再到「领退和计划」导入领用表与计划表。

> 程序是**单实例**的：同一个 Windows 用户重复双击图标，不会开出第二个程序，而是把已经打开的窗口显示到最前面。

## 主界面

主窗口左侧是品牌区（Logo、程序名、版本号），右侧按权限显示四个入口：

| 按钮 | 需要的权限 | 说明 |
| --- | --- | --- |
| 一键报告 | `report.use` | 读取报告概览并自动生成报告 |
| 领退和计划 | `plan.view` | 领退与计划数据的查看与编辑 |
| 管理 | `admin.manage` | 人员/客户/测试项目/产品别/阶段管理与数据导入 |
| 审核 | `review.view` | 审核计划表单更改请求（按钮上显示待审核条数） |
| 用户 | — | 用户中心（个人资料/改密码）与登录/注销 |

菜单栏：

- **设置**：打开设置窗口（见下）。
- **帮助 → 查看日志**：按日期/级别/关键字筛选运行日志。
- **帮助 → 更新日志**：按版本查看本程序的更新记录（最新在上）。
- **注销**：退出登录（未登录时是「登录」，点它弹出登录窗口）。

## 设置说明

设置窗口参考 VSCode：左侧目录 + 右侧详情，**改完点「保存」或「应用」才生效**（取消即时保存）。部分小节仅管理员可见。

### 界面

- **UI 方案**：内置 Fluent / Material / DarkLab 等主题，支持导入自定义 XAML 主题（无需重新编译）。
- **语言**：简体中文 / 繁體中文 / English，切换立即生效。
- **字体**：全局字体族、字号（8–24）、字重、Toast 提示位置。字号变大时窗口尺寸、标签与表格列宽会一起等比放大。
- **主界面背景图**：选一张图片铺满主界面（带淡淡遮罩保证可读），可随时清除。

### 路径

| 设置 | 用途 |
| --- | --- |
| ATE 数据路径 | 选择 ATE 数据时的默认打开目录（**保存在本机**） |
| EMI 数据路径 | 选择 EMI 数据时的默认打开目录（**保存在本机**） |
| 数据文件夹 | 数据库、附件、配图所在目录（**仅管理员，改后需重启**，**保存在本机**） |
| 计划表路径 | 导入计划表（ORT Test Schedule）的默认目录 |
| 领用表路径 | 导入领用表（成品領用記錄）的默认目录 |
| 报告路径 | 一键报告选择报告概览的默认打开目录 |

「数据文件夹」可以填网络共享（`\\服务器\共享\目录`）：程序会自动把它映射成一个网络驱动器再访问（SQLite 不能直接用 UNC 路径），也可以直接填已映射好的盘符（如 `Z:\...`）。

### 邮件服务

仅管理员可维护，含总开关、通知类/警告类开关、SMTP 服务器与端口、安全方式（明文 25 / STARTTLS 587 / SSL 465）、忽略证书错误、Windows 集成验证、发件账号与密码、发件地址与显示名、固定抄送、超时、提前提醒天数、重复发送间隔、按类型抄送管理员、邮件模板与最近发送记录。

- 密码以 **DPAPI（当前 Windows 用户）** 加密后入库，不保存明文。
- 模板标记：`{{变量}}` 输出变量，`{{变量|格式}}` 按格式输出（如 `{{EndDate|yyyy/MM/dd}}`）；清空模板即恢复内置默认模板。
- 可「发送测试邮件」，也可「立即检查并发送警告」。

### 计划索引 / 报告扫描

- **计划索引**：空闲 N 分钟后自动为计划表建立索引，加快搜索与筛选。
- **报告扫描**：空闲 N 秒后自动扫描报告文件夹，回写每份计划的「报告状态」（已完成 / 进行中 / 无要求）。

两者都与「一键报告」互斥：同一时间只跑一个高耗时任务，切换任务时会先中断上一个。

### 后台运行

| 设置 | 说明 |
| --- | --- |
| 关闭主窗口时先询问是否最小化到后台 | 默认开启。关闭主窗口时先问：**最小化到后台**（收进右下角托盘、顺手清理一次内存、程序继续在后台跑自动扫描与邮件提醒）或**退出程序**；直接关掉询问框＝什么都不做。 |
| 开机自启（当前用户） | 登记到当前用户的注册表启动项，登录 Windows 后自动运行，**不需要管理员权限**；任务管理器的「启动」页也能看到并关闭。 |
| 开机自启时直接进后台 | 勾选后开机自启不弹主窗口，直接收进托盘（需要登录时仍会先弹登录窗口）。 |

最小化到后台后：双击托盘图标恢复窗口，右键托盘图标可「显示主窗口」或「退出程序」。

> **远程路径不能开机自启。** 程序位于网络共享（`\\服务器\共享\...`）、映射的网络盘符或 SUBST 虚拟盘时，「开机自启」会被禁用并给出提示——登录那一刻网络往往还没就绪，登记了也会自启失败。把程序解压到本机磁盘后再设置。

## 数据与文件位置

程序区分「跟着数据走」和「留在本机」两类设置，便于多台电脑共用同一套数据：

| 位置 | 内容 |
| --- | --- |
| **数据文件夹**（默认 `程序目录\Data`，可在设置里改为共享目录） | `ort_plans.db`（SQLite 主库：计划、领用、审核、用户、邮件记录等）、附件（`OleFiles`）、计划配图（`PlanImages`）、报告链接与状态。 |
| `程序目录\Data\local_settings.json` | **本机设置**：数据文件夹、ATE/EMI 路径、计划表列布局、[后台运行](#后台运行)（最小化到后台 / 开机自启）。 |
| `%LocalAppData%`（当前用户目录） | 登录凭据（「记住登录」的用户名与 DPAPI 加密密码），同一台电脑不同用户互不覆盖。 |
| `程序目录\current_language.txt` / `current_theme.txt` | 当前语言与主题。 |
| `程序目录\logs\` | 运行日志（NLog，按天分文件）。 |
| `程序目录\temp` 或系统临时目录下的 `ORTTemp` | 生成报告时的临时文件，退出时自动清理。 |

数据库为 SQLite + FreeSql（`UseAutoSyncStructure(true)`），新增字段会**自动迁移**，升级时不需要手工改库。

## 从源码构建

需要 Visual Studio 2022/2026（含 .NET 桌面开发工作负载）与 .NET Framework 4.8 目标包。用 MSBuild 命令行构建：

```powershell
MSBuild .\ORT一键报告.csproj /p:Configuration=Debug /p:SignManifests=false /p:GenerateManifests=false /v:minimal /nologo /t:Rebuild
```

说明：

- `SignManifests=false /p:GenerateManifests=false`：受限环境下清单签名会失败，与代码无关；正式发布时可去掉这两个参数用 Visual Studio 发布。
- 输出：`bin\Debug\ORT实验室管理系统.exe`（Release 为 `bin\Release\`）。
- 重建 `bin\Debug\*` 前先确认没有 `ORT实验室管理系统.exe` 在运行，否则 `SQLite.Interop.dll` 会被占用导致生成失败。
- 根目录 `更新日志.md` 与 `Templates\` 会随生成自动复制到输出目录，发布包自带更新日志。

## 常见问题

**Q：程序能不能放在网络共享里直接运行？**
可以运行，但**不能设置开机自启**（登录时网络通常还没就绪）。另外网络共享上运行会明显变慢，建议把程序解压到本机磁盘；需要共享数据时，只在「设置 → 数据文件夹」里指向共享目录即可。

**Q：双击图标没有反应 / 只弹出一个已有窗口？**
程序是单实例的。如果已经有一个在运行（含最小化到后台），新的一次启动会**把已有窗口显示到最前面**然后自己退出，这是预期行为；托盘图标（在后台运行时）双击同样恢复窗口。

**Q：数据文件夹配成共享路径后启动失败？**
程序会尝试自动把 `\\服务器\共享` 映射成盘符；失败时按提示手工执行一次 `net use Z: \\服务器\共享 /persistent:yes`，再把数据文件夹填成 `Z:\对应目录`。临时映射失败时程序会回退到程序目录下的默认 `Data` 并提示，不会清掉你的配置。

**Q：改了数据文件夹为什么没生效？**
数据文件夹改后需要重启程序，程序会问你是否**立即重启**、以及是否把现有数据复制到新文件夹。

**Q：界面字太小/太大？**
「设置 → 界面 → 字体」里调字号（8–24）。字号变大时窗口与表格尺寸会等比放大，超过上限会被拒绝并提示。

**Q：计划表/领退表的列怎么调？**
列宽、列顺序、显示隐藏都会**按电脑记住**，重开窗口保持上次的样子（存在本机 `local_settings.json`）。

**Q：忘记管理员密码怎么办？**
由另一个管理员账号在「管理 → 人员管理」里重置。
