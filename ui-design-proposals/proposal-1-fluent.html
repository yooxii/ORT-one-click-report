📦 推荐 NuGet 包

  • iNKORE.UI.WPF.Modern — Fluent 2 控件库，提供 NavigationView、ModernButton、ModernWindow 等 50+ 控件
  • iNKORE.UI.WPF.Modern.Controls — 附加控件（ TeachingTip、CommandBar 等）

🔧 实施步骤

  • 1. NuGet 安装 iNKORE.UI.WPF.Modern
  • 2. App.xaml 引入 Fluent 主题资源字典
  • 3. MainWindow 改为 NavigationView + Content 布局
  • 4. 逐个窗口替换控件（Button → ModernButton, TextBox → ModernTextBox 等）
  • 5. 添加 Mica 背景效果（需 Windows 11）
  • 6. 配置浅色/深色主题切换

⏱️ 预计工期

  • 基础框架搭建（NavigationView + 主题）：0.5 天
  • 主窗口 + 登录窗口改造：0.5 天
  • 领退计划窗口（DataGrid 样式）：0.5 天
  • 报告/管理/审核/设置窗口：1 天
  • 测试与微调：0.5 天
  • 合计：约 3 天
